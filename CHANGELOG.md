## 3.3.0 — обновление

- IPv6: статус различает состояние ядра, публичный адрес и маршрут по умолчанию; внешняя IPv6-связь проверяется отдельно по запросу с коротким таймаутом.
- Пользователи: добавлены список обычных аккаунтов, отображение текущего входа и прав sudo, безопасное удаление с защитой текущей сессии и последнего sudo-администратора.
- Менеджер пользователей: выбор аккаунта по номеру, статус пароля (`passwd -S`), смена пароля, выдача и отзыв sudo, блокировка пароля и добавление публичного SSH-ключа.
- Удаление пользователя подтверждается ASCII-командой `delete`, поэтому не зависит от русской локали и преобразования регистра.
- Мастер быстрой настройки запускает создание sudo-пользователя напрямую; пункт главного меню переименован в «Пользователи».

- IPv6: безопасное включение/отключение через sysctl, отображение состояния, глобальных адресов и настройки IPv6 в UFW.
- IPv6: при ошибке отключения восстанавливаются исходные значения sysctl и удаляется незавершённый конфиг.
- IPv6: включение блокируется, если UFW активен, но поддержка IPv6 в нём не включена (`IPV6=yes`).
- Добавлены отдельные автотесты переключения IPv6.

- NetBird (клавиша `n` в главном меню): установка официальным скриптом с проверкой «уже установлен?», подключение по setup-ключу (ввод скрыт, ключ передаётся клиенту через переменную окружения и не попадает ни в журнал, ни в список процессов; поддерживается свой сервер по Management URL), статус, отключение и повторное подключение, обновление, журнал, удаление.
- «SSH только через NetBird»: безопасная схема в два шага. Шаг 1 добавляет правило UFW для интерфейса NetBird (публичный доступ пока остаётся), после проверки входа шаг 2 закрывает публичный SSH, есть откат. Удаление NetBird блокируется, пока SSH закрыт для интернета, чтобы не отрезать тебя от сервера.
- NetBird в Dashboard (статус, IP, число пиров), в аудите (подсказка «SSH открыт всему интернету, хотя NetBird подключён» или подтверждение «SSH только через NetBird») и в профилях (ключ `NETBIRD`, установка).
- Исправлено: `ufw_is_active` и ещё несколько проверок читали вывод через `grep -q` при `pipefail` — при длинном выводе возможен ложный отказ (SIGPIPE), UFW мог считаться выключенным. Теперь вывод сначала сохраняется, есть регрессионный тест.
- Вывод `systemctl` в проверках служб теперь полностью подавляется.
- Автотесты NetBird (`tests/netbird.sh`) на заглушках `netbird` и `ufw`, общий запуск: `bash tests/run.sh`.
