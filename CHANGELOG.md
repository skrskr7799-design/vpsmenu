## 3.0.0
- Исходники разбиты на модули: `src/*.sh`, а `vpsmenu.sh` теперь собирается командой `./build.sh`. Для серверов ничего не меняется: ставится и обновляется тот же один файл.
- Новое ядро интерфейса: рамка-заголовок с «хлебными крошками» (`vpsmenu › Remnanode › Watchdog`), выбор пунктов одной клавишей без Enter (двузначные — двумя цифрами подряд), Esc или q — назад, горячие клавиши-буквы, подтверждения одной клавишей (y/n или д/н), «любая клавиша» вместо Enter, шкалы, разделители, спиннер, поддержка `NO_COLOR`, ровное выравнивание кириллицы, компактный режим для узких терминалов (телефон).
- Dashboard (клавиша `d` в главном меню или `vpsmenu --dashboard`): CPU, RAM, swap и диски со шкалами, сеть и трафик, упавшие службы, контейнеры Docker и состояние Remnanode, безопасность (сессии, неудачные входы по SSH за сутки и главные источники, баны fail2ban, обновления безопасности, перезагрузка). Обновление по клавише `r`, автообновление каждые 5 с по клавише `a`.
- Автотесты (`tests/unit.sh`) и проверка в CI, что собранный `vpsmenu.sh` соответствует `src/`.

## 2.1.0
- Watchdog для Remnanode: если нода упала, в главном меню появляется красная пометка со временем падения. Автоперезапуск настраивается отдельно и по умолчанию выключен (интервал проверки и число попыток тоже настраиваются). Остановка ноды вручную из меню не считается падением.
- Профили серверов: готовые наборы (полный стек для ноды, минимальная защита, усиленная защита), ручная настройка с вопросами, сохранение своих профилей, загрузка профилей из репозитория (`profiles/<имя>.conf`).
- Диагностика сети: тест скорости (speedtest-cli с проверкой «уже установлен?»), задержка, доступность GitHub/Docker Hub/apt, внешний IP, слушающие порты.
- Внутри: шаги настройки вынесены в функции без вопросов (их используют и меню, и профили); репозиторий обновлений запоминается в `/etc/vpsmenu.conf`.

## 2.0.0
- Самообновление из GitHub: меню «Сам скрипт» → «Обновить», либо `vpsmenu --update`. Перед заменой сохраняется копия текущей версии, есть откат. Раз в сутки скрипт тихо проверяет, не вышла ли новая версия.
- Мастер быстрой настройки: все шаги подряд, каждый можно пропустить.
- SSH: добавление публичного ключа, вход только по ключам (и возврат пароля), безопасная смена порта в два шага (сначала добавить новый, потом закрыть старый).
- Оптимизация: обновление системы, часовой пояс и NTP, BBR, swap, автообновления безопасности.
- Docker: ротация логов контейнеров, очистка места, список контейнеров и ресурсов.
- Remnanode: логи xray (`xlogs`, `xerrors`), консоль контейнера, бэкап и восстановление конфигов.
- Бэкап конфигов сервера одним пунктом (последние 10 копий, доступ только root).
- Панель статусов: порт SSH, вход по паролю, BBR, swap, автообновления.

## 1.0.0
- Первая версия: sudo-пользователь, запрет root по SSH, UFW, nftables, Fail2ban, Docker, Remnanode, WARP Native. Установка скрипта в систему командой `vpsmenu`.
